# Iconos PWA - MultiCatálogo

Los iconos actuales son **provisionales** (letra "M" blanca sobre rosa #ec4899).
Reemplázalos por el logo definitivo conservando los nombres y tamaños:

| Archivo | Tamaño | Uso |
|---|---|---|
| `icon-192x192.png` | 192x192 | Android / manifest |
| `icon-512x512.png` | 512x512 | Android / manifest / splash |
| `icon-maskable-512x512.png` | 512x512 | Android adaptativo: deja el logo dentro del 80 % central (zona segura) |
| `apple-touch-icon.png` | 180x180 | iOS (pantalla de inicio) |
| `favicon.ico` | 16/32/48 | Pestaña del navegador |

Herramienta útil para generarlos desde un logo: https://realfavicongenerator.net/ o https://maskable.app/editor (previsualizar el maskable).
